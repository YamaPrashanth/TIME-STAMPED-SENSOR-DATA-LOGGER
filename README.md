# ⏱️ TIME-STAMPED SENSOR DATA LOGGER

## 📌 Project Description
The Time-Stamped Sensor Data Logger is an embedded systems project that records real-time temperature readings using LM35 sensors along with accurate date and time information. It helps in monitoring, analysis, fault detection, and maintaining historical data for various applications.

## 🎯 Objectives
- To log sensor data with date and time
- To maintain historical records for analysis
- To understand real-time data handling using embedded systems

## ⚙️ Tools & Technologies
- Keil µVision IDE
- Embedded C
- Microcontroller (LPC2148)
- Real-Time Clock (RTC)
- LM35 sensor

## 🔍 Features
- Accurate time-stamped data logging
- Continuous or periodic sensor monitoring
- Simple and efficient embedded implementation
- Suitable for learning and real-world applications

## 🛠️ Working Principle
The microcontroller reads sensor data at fixed intervals. The current date and time are obtained from the RTC and combined with the real-time temperature readings. This information is stored as a log entry for future analysis.

## 🚀 Applications
- Industrial monitoring
- Environmental data logging
- Research and analysis
- Embedded systems projects
